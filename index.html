Giọng nói của Skye

Skye dùng Google Cloud Text-to-Speech làm giọng chính. Key Gemini ở trên thường không dùng chung được (Google giới hạn loại key đó chỉ gọi được Gemini), nên cần 1 mã API riêng — tạo tại Google Cloud Console → Credentials → Create credentials → API key, rồi vào phần API restrictions của key đó bật quyền Cloud Text-to-Speech API. Nếu chưa nhập hoặc lỗi mạng, Skye tự chuyển sang giọng Gemini hoặc giọng dự phòng của máy.

Giọng Gemini cho khoảnh khắc đặc biệt

Giọng do AI tạo, nghe như bé thật. Hạn mức miễn phí chỉ 10 lượt mỗi ngày và mỗi câu mất khoảng 7 giây. Hết hạn mức, Skye tự quay về Cloud TTS hoặc giọng máy.

Hạn mức hôm nay

Hạn mức miễn phí đặt lại lúc 15:00 giờ Việt Nam (nửa đêm giờ Thái Bình Dương). Skye tự dừng trước khi chạm trần để không bỏ dở giữa chừng.
